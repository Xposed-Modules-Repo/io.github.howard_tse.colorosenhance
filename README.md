# ColorOS 增强

面向 ColorOS 16 / Android 16、ColorOS 17 / Android 17 的 LSPosed 模块。作者：**Howard**（[Howard-Tse](https://github.com/Howard-Tse)）。当前稳定版本为 **1.32.2**，应用包名：`io.github.howard_tse.colorosenhance`。

预发布版本见 [1.32.4](https://github.com/Xposed-Modules-Repo/io.github.howard_tse.colorosenhance/releases/tag/76-1.32.4)。

1.32.4 预发布版支持长按合并卡片进入收纳页并展开本组通知。可在「原通知处理」开启「锁屏时保留通知转流体云」，再按需开启「锁屏时显示通知流体云卡片」。两个选项均默认关闭，并遵循系统锁屏隐私设置。

旧包 `dev.howard.colorosenhance` 的用户应保留旧包和数据，安装并首次打开新版，按提示允许 root 读取以自动迁移设置。检测到旧模块仍启用时会提示在 LSPosed 取消旧版启用；返回后自动继续，最后完整重启并确认新版正常，再卸载旧包。无需先更新旧 APK 或手动导出文件，详见[迁移说明](https://github.com/Howard-Tse/ColorOS-Enhance/blob/main/docs/MIGRATION.md)。

模块包含系统私有接口适配，不同机型、主题及系统更新后的效果可能不同。本项目不是 OPPO 或 OnePlus 官方产品。

下载与反馈：[Release 下载](https://github.com/Howard-Tse/ColorOS-Enhance/releases) · [LSPosed 模块仓库](https://github.com/Xposed-Modules-Repo/io.github.howard_tse.colorosenhance) · [GitHub Issues](https://github.com/Howard-Tse/ColorOS-Enhance/issues)。提交前请阅读[问题反馈规则](#问题反馈)。

## 功能

- **状态栏图标**：蓝牙显示条件、时钟／电池及系统图标仅下拉显示、锁屏规则、自定义排序和左右区域移动；配合系统自身的图标开关。
- **控制中心增强**：竖屏可将下方分页磁贴纵向展开，滚动整个控制中心；横屏可独立选择保留原生分栏后纵向滚动，或为原来的左右分页增加外侧边缘渐隐。左右切换通知中心和控制中心时沿用系统绘制。磁贴翻页时仅在分页外侧淡出，范围按相邻控件间距限制。各项默认关闭，编辑磁贴时恢复原厂布局。
- **状态栏电池增强**：电量文字字重、位置等参数。
- **全景息屏增强**：日期／组件显示和背景压暗等参数，按系统能力适配。
- **流体云增强**：在「场景与方向」开启状态栏解绑并重启系统界面，再配置竖屏或横屏的全屏、最近任务、下拉等场景。未配置的场景沿用系统行为。1.32.3 新增「锁屏时收缩胶囊」，可独立开启，默认关闭。
- **胶囊与卡片**：尺寸比例、可分别配置的竖屏和横屏位置、边框、切换箭头、循环切换、当前胶囊卡片优先、摄像头区域展开、圆角和连续曲线、展开背景压暗。展开卡片圆角最高可设为 96 dp。
- **媒体流体云**：暂停／未开始播放时显示；六频段实时律动、可拖动频率轴、读取间隔与其他参数、暂停冻结柱高。采集不可用时回退原厂效果。
- **SIM PIN 自动解锁**：独立卡槽配置、加密存储、卡片匹配和每卡每次开机一次尝试保护。
- **安装器替换**：选择可处理 APK 的应用；可选跳过针对该安装器的普通打开确认。

1.32.0 新增通知转流体云、通知中心媒体卡片、控制中心滚动边界震动，以及模块状态与诊断日志导出。设置和默认行为见[通知转换说明](https://github.com/Howard-Tse/ColorOS-Enhance/blob/main/docs/NOTIFICATION_CLOUD.md)。升级后请完整重启手机。

本版的「模块状态」支持保存诊断 ZIP，记录 ColorOS、系统组件和 Seedling SDK 版本，可附上用于适配的关键系统接口。升级保留现有设置。

小胶囊位置在「流体云 → 小胶囊与交互 → 小胶囊位置」分别设置。自 1.32.3 起，竖屏解锁时可将胶囊下移至状态栏下方，点击区域同步移动。升级后原有偏移归入竖屏，横屏默认使用原厂位置。

提供独立设置应用和「系统设置 → 系统与更新」中的内嵌入口。数值参数支持滑条、手动输入及长按恢复单项默认值；六频段编辑器有独立恢复入口。各功能组首次安装默认关闭，升级保留已有配置。

媒体实时律动只采集经过安全检查的普通 PCM 输出中的私有媒体会话，不使用麦克风或全局混音，不强制关闭硬件卸载。采集路径按接口能力选择，适用于符合条件的扬声器、有线／USB 耳机和蓝牙输出；无法安全采集时保留原厂动画。较新的可视化接口使用最新采样窗口与六柱高度延迟队列，避开系统环形缓冲区跨界时重复返回旧数据的问题，并补偿原有声音输出延迟；不支持该接口时保留旧采集方式。频谱计算沿用六频段、灵敏度及过渡设置，停止采集时释放资源并恢复原有可视化延迟参数。

控制中心纵向展开时，普通区域上下滑动用于滚动；从底部手势条附近上滑，或已经滚到底后重新上滑，交给系统收起面板，底部仍在回弹时也遵循这个规则。亮度／音量滑条保留原生操作。滚动与分区回弹优先复用通知中心的独立引擎，底部回弹幅度单独收敛；面板接近展开终点后即可滚动，不必等待弹簧尾段完全停止。此功能按原生网格与触摸接口检测能力，接口不匹配时保留系统处理；已在部分 ColorOS 17 固件验证，不代表所有固件均已验证。

应用打开进入前台时自动检查一次官方模块仓库，有更新才弹窗，网络失败或没有更新时不打扰。默认只检查正式版。自 1.32.3 起，在「检查更新」页开启「优先检查预发布版本」后，启动和手动检查均可发现比正式版更新的预发布版。更新弹窗和「检查更新」页面支持显示 Markdown 格式的版本说明。进入二级页面、旋转屏幕不重复检查，迁移引导未完成时暂缓提醒。独立应用「管理 → 关于」及内嵌页「关于」也保留手动检查和源码仓库入口。检查按 `versionCode-versionName` 中的版本码比较，显示版本说明，有更新时可交给浏览器下载 APK。不包含后台定时检查、静默下载或安装。

## 使用要求

- 对应 ColorOS 的 Android 16 或 Android 17；最低 Android API 36。
- 支持现代 **libxposed API 102** 的 LSPosed 实现。只支持旧 API 的框架不能加载本模块。
- 已安装可用的 root／LSPosed 环境。管理页重启进程功能另需授予模块应用 root 权限。

建议只勾选模块声明的作用域：系统界面、设置、电话、系统框架，以及 ColorOS 17 背景压暗所需的多彩引擎。包名分别为 `com.android.systemui`、`com.android.settings`、`com.android.phone`、`system`、`com.heytap.colorfulengine`；系统框架应选择管理器中的对应项目。

安装后启用模块及所需作用域，并首次打开应用完成初始化或旧包迁移，再完整重启一次。系统框架／多彩引擎中的更新需要完整重启；管理页的「重启系统界面」或「一键重启作用域」不能替代。应用转场胶囊保持功能首次使用也需要完整重启。

## SIM PIN 与安装器

真实 PIN 只在手机设置页输入，不放进源码、截图、Issue 或日志。首次使用需要配置各卡槽；本产品更换包名时保留电话端已确认凭据，未确认暂存 PIN 不导出，独立旧 SIM 模块的凭据不迁移。关闭总开关保留已保存凭据；换卡或修改 PIN 后应重新配置。失败或不匹配时恢复手动输入。停用模块并完整重启，可恢复原厂流程。

安装器替换需要自行安装并配置目标应用。没有选择目标、目标不可用或请求不符合条件时走原系统流程；本功能不会替代安装器的权限和安装后端，也不会确认安装。

## 构建

工具版本以工程为准：JDK 21、Android SDK 37、Build Tools 37.0.0、Gradle Wrapper 9.5.1、AGP 9.2.1。使用仓库中的 Wrapper；不包含 SDK、JDK 或私有签名。

Windows PowerShell：

```powershell
# 预先配置 JAVA_HOME，以及 ANDROID_HOME 或 ANDROID_SDK_ROOT。
# 使用共享环境时，也可设置 CODEX_ANDROID_ROOT 指向其目录。
.\scripts\build.ps1
```

脚本优先离线构建，执行单元测试、Lint 和 Debug 构建；首次使用的机器应先准备工程声明的 SDK／依赖。Debug 签名首次生成在已忽略的 `.local/`。

Release 构建：

```powershell
. .\scripts\Enter-AndroidEnvironment.ps1
# 仅首次创建自己的发布签名时运行；已有正式密钥时不要重建。
.\scripts\Initialize-ReleaseSigning.ps1
.\scripts\build.ps1 -Release
```

Debug 与正式 Release 签名不同。自行构建的 APK 不能用来直接覆盖另一签名的安装。正式发布方应安全备份 `.signing/`，后续版本沿用同一签名；密钥和密码文件永不提交。

## 适配与验证

当前实现保留 ColorOS 16 及较早 ColorOS 17 路径，并适配过 ColorOS 17 的新插件接口。1.32.1 补充了 ColorOS 16.0.2.400 的 SystemUI 与 SystemUIPlugin 适配，已核对该固件的接口，仍需在对应机型上实测。自动化用例不能代替具体机型、主题或完整开机流程的真机验证。

1.32.0 的通知转换等新增功能主要在 ColorOS 17 开发测试中验证。ColorOS 16.0.2.400 的适配仍待验证和完善。

1.31.1 已通过 1227 项测试，Debug／Release Lint 无错误。媒体实时律动已在扬声器、蓝牙耳机及两者切换、暂停恢复和卡片开合后复测；本轮没有有线／USB 耳机实机验证。控制中心长按胶囊进入应用，以及低电量即现卡片在所有流体云退出后的首次展开、底部完整性和轮廓光位置均已验收；普通媒体与秒表卡片已作对照。旧接口路径保留，本轮未重新实测旧固件。升级保留设置，安装后重启系统界面或手机以加载修正。

1.31.0 已通过 1200 项测试，Debug／Release Lint 无错误。控制中心纵向滚动、快速交替分区回弹、横屏分页外侧渐隐，以及图标在屏幕内／离屏后的收起衔接已完成真机复测；独立应用底栏、页面切换、两处更新入口、内嵌页返回和计时卡片退场也已验收。控制中心新功能默认关闭，已验证的 ColorOS 17 固件不代表所有机型与固件。

1.30.0 的同签名旧包迁移、启用状态交接及完整重启已通过真机验证。暂存 PIN 不迁移，未以本轮验证代替 SIM PIN 自动解锁验证。

1.29.2 针对摄像头区域展开时自动弹出卡片的顶部定位增加补正，1.31.1 进一步修正首次尺寸准备和轮廓材质。耳机、低电量等即现卡片在原厂状态机稳定前可能不响应收起手势，目前保留这项系统限制。版本变更见 [CHANGELOG.md](https://github.com/Howard-Tse/ColorOS-Enhance/blob/main/CHANGELOG.md)。

## 问题反馈

提交前请搜索已有 Issue。同一问题已有记录时，请在原 Issue 补充。每个新 Issue 聚焦一个问题。功能建议请说明使用场景和期望行为。

**提交 Bug 必须附上模块导出的诊断 ZIP。** 请同时填写机型、完整 ColorOS 固件版本、模块版本、相关开关、复现步骤、预期结果和实际表现。偶发问题请补充发生时间和大致频率，方便对照日志。

复现后，打开独立的「ColorOS 增强」应用，进入「管理 → 模块状态 → 保存诊断包」。选择覆盖复现时间的日志范围，把保存的 ZIP 作为 Issue 附件上传。反馈固件适配问题时，建议开启「同时导出系统接口」。若应用无法打开或保存失败，请说明卡在哪一步，并补充上述信息。

上传前请检查附件并遮挡截图或录像中的个人信息。关于诊断包包含的内容与反馈注意事项，见[隐私说明](https://github.com/Howard-Tse/ColorOS-Enhance/blob/main/docs/PRIVACY.md#提交问题时)。
